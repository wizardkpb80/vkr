# XDTO-библиотека для обмена данными с системой ИИ (AIClishe / FactoryClishe)

Данная библиотека используется для формирования ответа веб-сервиса `ПрогнозированиеИИ`, а также сервиса `ПолучитьФайлыИзображений`.  
Содержит два пространства имён:

- `http://www.1c.ru/1cwai/AIClishe` – используется при отсутствии данных (информационное сообщение).
- `http://www.1c.ru/1cwsppf/FactoryClishe` – основной пакет для возврата данных из запросов №1, №2, №3 и получения изображений.

---

## 1. Пространство имён `http://www.1c.ru/1cwai/AIClishe`

### Тип `ObjectItem`
Корневой элемент, содержит табличную часть.

| Свойство | Тип       | Описание                  |
|----------|-----------|---------------------------|
| `Item`   | `Item[]`  | Массив строк (табличная часть) |

### Тип `Item`
Строка табличной части, используется только для информационного сообщения.

| Свойство         | Тип      | Описание                          |
|------------------|----------|-----------------------------------|
| `ItemMatrixName` | `string` | Текст сообщения (например, "Все заказы выполнены!" или "Нет файлов изображений...") |

---

## 2. Пространство имён `http://www.1c.ru/1cwsppf/FactoryClishe`

### Тип `ObjectItem`
Корневой элемент основного ответа.

| Свойство | Тип       | Описание                  |
|----------|-----------|---------------------------|
| `Item`   | `Item[]`  | Массив строк (табличная часть) |

### Тип `Item`
Основной тип строки табличной части. Содержит все поля, используемые в запросах №1, №2, №3 и в функции `ПолучитьФайлыИзображений`.

| Имя поля (свойство)        | Тип        | Описание / источник                                                                 | Где используется |
|----------------------------|------------|--------------------------------------------------------------------------------------|------------------|
| `Date`                     | `string`   | Дата документа (формат `dd.MM.yyyy ЧЧ:мм`)                                           | Запросы 1, 2; Получение Изображений |
| `OrderNo`                  | `string`   | Номер заказа (из ссылки документа)                                                   | Запросы 1, 2, 3; Получение Изображений |
| `CustomerName`             | `string`   | Наименование контрагента (запрос 1) или ресурса предприятия (запрос 2)              | Запросы 1, 2      |
| `ItemName`                 | `string`   | Наименование номенклатуры (запрос 1,2), операции (запрос 3) или файла (Получение Изображений) | 1, 2, 3, Получение Изображений |
| `Qty`                      | `string`   | Количество (запрос 1,2) или нормочасы (запрос 3)                                     | Запросы 1, 2, 3   |
| `Status`                   | `string`   | Состояние заказа                                                                     | Запросы 1, 2      |
| `Picture`                  | `string`   | Путь к файлам (запрос 2) или путь к файлу изображения (Получение Изображений)       | Запрос 2, Получение Изображений |
| `ClientOrderNo`            | `string`   | Дополнительная информация: для запроса 3 – `ppfФрезаЦанга`, для получения изображений – расширение файла | Запрос 3, Получение Изображений |
| `Currency`                 | `string`   | Валюта документа                                                                     | Запрос 1          |
| `CurrencyRate`             | `number`   | Курс валюты                                                                          | Запрос 1          |
| `Project`                  | `string`   | Проект                                                                               | Запрос 1          |
| `ProductType`              | `string`   | Вид продукции (из дополнительных реквизитов контрагента)                             | Запрос 1          |
| `Unit`                     | `string`   | Единица измерения                                                                    | Запрос 1          |
| `Price`                    | `number`   | Цена                                                                                 | Запрос 1          |
| `Capacity`                 | `number`   | Объем                                                                                | Запрос 1          |
| `NTKOperation`             | `string`   | Операция НТК                                                                         | Запрос 1          |
| `ProductHeight`            | `string`   | Высота продукции (доп. реквизит номенклатуры)                                        | Запрос 1          |
| `ProductLength`            | `string`   | Длина продукции (доп. реквизит номенклатуры)                                         | Запрос 1          |
| `ProductWidth`             | `string`   | Ширина продукции (доп. реквизит номенклатуры)                                        | Запрос 1          |
| `Material`                 | `string`   | Материал (номенклатура из состава спецификации)                                      | Запрос 1          |
| `ActualLength`             | `number`   | Длина реальная (из спецификации)                                                     | Запрос 1          |
| `ActualWidth`              | `number`   | Ширина реальная (из спецификации)                                                    | Запрос 1          |
| `NumberofOperations`       | `number`   | Количество операций в спецификации                                                   | Запрос 1          |
| `NumberofSpecifications`   | `number`   | Количество спецификаций                                                              | Запрос 1          |
| `OperationType`            | `string`   | Вид операции (запрос 2)                                                              | Запрос 2          |
| `OrderBuy`                 | `string`   | Заказ покупателя (ссылка)                                                            | Запрос 2          |
| `Quantity`                 | `number`   | Количество продукции (cnt из подзапроса)                                             | Запрос 2          |
| `PowerType`                | `string`   | Мощность / тип ресурса предприятия                                                   | Запрос 2          |
| `StartTime`                | `datetime` | Старт (время начала)                                                                 | Запрос 2          |
| `EndTime`                  | `datetime` | Финиш (время окончания)                                                              | Запрос 2          |
| `ArtCAMTime`               | `string`   | Время ArtCAM (доп. реквизит)                                                         | Запрос 2          |
| `Adjustment`               | `string`   | Корректировка (доп. реквизит)                                                        | Запрос 2          |
| `WorkingTime`              | `string`   | Время работы (доп. реквизит)                                                         | Запрос 2          |
| `Manufacturing`            | `string`   | Брак (доп. реквизит)                                                                 | Запрос 2          |

| `TestsCompleted`           | `string`   | Тесты выполнены (доп. реквизит)                                                      | Запрос 2          |
| `OrderNoLink`              | `string`   | Строковое представление ссылки на документ (используется в запросе 3 и в функции получения изображений) | Запрос 3, Получение Изображений |

> **Примечания:**  
> - Поля с типом `string` могут быть ограничены по длине (в коде используется `СокрЛП()` и при необходимости `Лев()`).  
> - Поля с типом `number` соответствуют `xsd:decimal` или `xsd:double`.  
> - Поля `StartTime` и `EndTime` имеют тип `datetime` (в XDTO рекомендуется `xsd:dateTime`).  
> - В запросе №1 поле `Status` заполняется из `з.СостояниеЗаказа`, в запросе №2 – аналогично.  
> - Поле `ClientOrderNo` в запросе №3 содержит значение `ppfФрезаЦанга`, а в функции получения изображений – расширение файла (например, "jpg").  
> - Поле `OrderNoLink` хранит ссылку на документ в виде строки (например, для идентификации заказа в запросе 3 и для связи файла с заказом).

## 3. Примеры использования (фрагменты кода 1С)

### 3.1. Создание пустого сообщения (нет данных)

```1c
ТипДокумента = ФабрикаXDTO.Тип("http://www.1c.ru/1cwai/AIClishe", "ObjectItem");
ПакетДокумента = ФабрикаXDTO.Создать(ТипДокумента);
ТипТабличнойЧасти = ФабрикаXDTO.Тип("http://www.1c.ru/1cwai/AIClishe", "Item");
ПакетДокументаТаб = ФабрикаXDTO.Создать(ТипТабличнойЧасти);
ПакетДокументаТаб.ItemMatrixName = "Все заказы выполнены!";
ПакетДокумента.Item.Добавить(ПакетДокументаТаб);
Возврат ПакетДокумента;
